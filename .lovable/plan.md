# 把这个互动文游放进抖音

## 结论先说

这个应用是 React 网页应用，不能直接变成抖音原生小游戏。要「在抖音里玩」，现实可行的路线是:**做一个抖音小程序外壳,用 web-view 组件把已发布的网页版整个嵌进去**。这是抖音官方支持的 H5 容器方案([官方文档](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/tutorial/basic-ability/web-view-component))。

另一条路(重写为抖音小游戏引擎代码)等于推倒重做,不推荐。

## 需要你准备的(平台侧,我无法代劳)

1. **企业主体的抖音小程序账号** —— web-view 组件不支持个人类型小程序,需要企业认证。
2. **一个你自己的域名** —— web-view 要求配置「业务域名」,并且要把校验文件放到域名根目录,所以 `*.lovable.app` 这种平台域名不行,必须绑定自定义域名。
3. 在小程序后台把该域名加为业务域名。

## 我这边要改的(代码侧)

1. **真机自适应**:目前页面套在 `PhoneMockup` 手机壳里展示。增加检测:在真实手机浏览器/抖音 web-view 里打开时,去掉手机壳,内容直接铺满全屏。
2. **绑定自定义域名**:用 Lovable 的域名绑定功能把你的域名指到已发布版本。
3. **小程序外壳代码**:给你生成一个最小抖音小程序工程(一个页面 + web-view 组件指向你的域名),你在抖音开发者工具里上传即可。
4. **(可选)抖音登录对接**:网页内通过 js-bridge 调用小程序的 `tt.login`,让抖音用户身份传入剧情进度;这一步等你确认需要再做。

## 步骤顺序

1. 我改代码:去手机壳的自适应 + 发布
2. 你买/提供域名 → 我帮你绑定
3. 我生成小程序外壳工程 → 你在抖音开发者工具上传、配置业务域名、提审

## 技术细节

- web-view 要求业务域名可放置校验文件 → 必须用自有域名的根路径
- 小程序审核对内容类目有要求,互动阅读/剧情类一般走「文娱-小说阅读」或游戏类目,游戏类目需要版号,剧情互动类建议按阅读类目申报
- 抖音内无法使用微信系或 Google 登录;现有登录若需要,改用 tt.login 桥接
